# Security policy

Please report suspected vulnerabilities privately so maintainers can assess the impact and coordinate a fix before public disclosure.

## Report a vulnerability

1. Open the affected repository's **Security** tab and look for **Report a vulnerability**.
2. If private reporting is available, submit the report there.
3. If the affected repository does not offer private reporting, or the concern spans multiple Formato24 Open Source repositories, use the [private reporting form in `.github`](https://github.com/formato24-os/.github/security/advisories/new). This channel is enabled for this repository. A GitHub account is required.

Include the affected repository and version or commit, a description of the issue, prerequisites, likely impact, and minimal steps or a safe proof of concept. Remove credentials and personal data from attachments and logs. Do not open a public issue or pull request containing an undisclosed vulnerability.

Only investigate systems you are authorized to test. Avoid accessing other people's data or disrupting services.

## Supported versions

Each project should state its supported releases in its own security policy. When a project has no published support policy, report the issue with its exact version or commit so maintainers can assess it. This shared policy does not establish long-term support or promise fixes for every version.

## Coordination and disclosure

Maintainers will assess reports as availability permits and use the private report thread to request details and coordinate next steps. There is no guaranteed response time or paid bug bounty program established by this policy.

Please coordinate public disclosure with the affected maintainers. When a fix or mitigation is ready, maintainers should document the impact, affected versions, and recommended action in an advisory or release note. Reporter credit should be included only with the reporter's consent.

For routine bugs and usage questions, see [Support](https://github.com/formato24-os/.github/blob/main/SUPPORT.md).
